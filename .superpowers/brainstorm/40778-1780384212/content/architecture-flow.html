方案 C：全管道架構對比

三個地方介入：拆解策略 × 語意注入 × 查詢過濾

❌ 現況（category/tags 沒有作用）
上傳檔案 / 輸入內容
category 選好了，tags 打好了
↓
Chunking
只看副檔名（xlsx/pdf/txt…）
❌ 不管 category
↓
Embedding
純文字 chunk 送入
❌ 不含 category/tags
↓
Indexing（向量 DB）
存向量 + 原文
❌ 沒有 metadata
↓
Search
全域向量搜尋
❌ 無法過濾分類
✅ 方案 C 改造後
上傳檔案 / 輸入內容
category + tags 帶入 pipeline
↓
① Category-Aware Chunking
依分類套策略：
商品文件 → 表格行拆解
客服知識 → Q&A 配對拆解
規則說明 → 條款段落拆解
系統文件 → 章節拆解
↓
② Metadata Prefix 注入
[分類:客服知識][標籤:退款]
原始 chunk 內容...
↓
Embedding
向量帶有分類語意
+ 存 metadata { category, tags }
↓
③ Search + Category Filter
search(query,
  filter: { category })

三個介入點可以分期實作——先做 ① 效果最大，② 成本最低，③ 需要後端配合
