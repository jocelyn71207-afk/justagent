「從共用檔案管理選檔案」的 UI 呈現方式

在「建立知識彈窗 → 上傳檔案」區塊中，如何讓使用者選擇「從共用檔案管理選取」？

📁 上傳新檔案
🗄 從共用庫選取
☁️
拖曳檔案至此或點擊選取
PDF、DOCX、XLSX，最大 50MB

A — 頁籤切換（Tab）

在 FILE 區塊內加入兩個頁籤：「上傳新檔案」和「從共用庫選取」。兩者同層，切換即可。

📄
上傳檔案
🗄
共用庫
🔌
API
✏️
手動
點擊瀏覽共用檔案管理...
選擇檔案

B — 新增來源類型卡片

在現有 FILE / API / MANUAL 旁邊新增第四個「共用庫」來源類型卡，與其他選項同等地位。

☁️
拖曳檔案至此或點擊選取
PDF、DOCX、XLSX，最大 50MB
— 或 —
🗄 從共用檔案管理選取

C — 上傳區下方加入連結按鈕

保留現有上傳拖曳區不變，在下方加一個「或從共用庫選取」的次要按鈕，保持上傳為主要入口。
