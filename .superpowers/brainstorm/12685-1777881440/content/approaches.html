實作策略選擇

三種方式將 Jade Mist 02 套用到整個產品，請選一個

A

漸進式疊加 — 新 token + 更新元件 推薦

在 _theme.scss 新增 Jade Mist 02 的 CSS 變數（--page-bg、--surface、--sidebar-bg… 含 dark），同時把現有元件的硬碼色值 & 舊 token 改指向新 token。舊的 --color-* 保留作相容橋接，後續逐步清除。

優點
  • 風險低，元件不會突然跑版
  • AiViewer 可以最後再單獨處理
  • Dark mode 一次到位
  • 字體、shadow、間距同步更新
缺點
  • 短期內新舊 token 並存
  • 需要手動更新每個元件
工作量：大（涵蓋全產品）。改動 _theme.scss、_variables.scss、_layout.scss、所有 components/*.scss、views/*.scss，加上 index.html 字體載入。
B

全量替換 — 直接覆寫所有 token 命名

完全用 Jade Mist 02 的 token 名稱取代現有的 --color-* 系統，全域搜尋替換所有引用。

優點
  • 最乾淨，無殘留舊 token
  • token 命名完全符合 design.md
缺點
  • 風險最高，容易漏改造成白屏
  • 第三方套件樣式可能失效
  • AiViewer 複雜度高，容易出錯
C

只改值，不改名 — 原地更新色值

維持現有 --color-* 變數名稱，只把顏色值改成 Jade Mist 02 的色值，然後只補上少數 design.md 特有的新 token。

優點
  • 改動範圍最小
  • 零破壞性
缺點
  • token 語意與 design.md 不一致
  • 元件細節（shadow、間距、字體）未更新
  • 不符合「全面調整」的需求

點選後在 terminal 確認，或直接說「選 A」
