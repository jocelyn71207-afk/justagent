兩種實作策略，你傾向哪一個？

視覺效果相近，差別在改動範圍

A

SCSS 優先（改動小）

盡量只改 _Explore.scss，HTML 結構維持不動。 用 CSS 漸層、box-shadow、偽元素 ::before 做裝飾光暈， 動畫全用 @keyframes。

優點

  • 風險最低，不動 Vue 邏輯
  • 容易 diff review

限制

  • Hero 裝飾元素較難做複雜
  • rec-card 加 icon 需微調 HTML
B ✦ 推薦

HTML + SCSS 一起調（彈性高）

Hero 加幾個裝飾 div（光暈球、背景漸層層）， rec-card 加上 icon，其餘邏輯完全不動。 SCSS 配合做 glow / animation / gradient border。

優點

  • Hero 漸層效果更自然飽滿
  • rec-card 可以顯示各自的 icon + 顏色
  • 動畫質感更到位

限制

  • HTML 變動略多（但僅限 Explore.vue）
