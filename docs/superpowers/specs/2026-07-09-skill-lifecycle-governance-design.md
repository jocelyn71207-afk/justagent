# Skill 生命週期與治理設計規格

**日期：** 2026-07-09
**範圍：** Skill 個人區、Library、來源追蹤、送審流程、版本更新提醒

---

## 背景

Skill 系統需要支援兩種使用層次：個人使用的實驗性 skill，以及跨團隊共享的穩定 Library skill。兩者之間需要明確的生命週期管理，包含晉升路徑、版本追蹤、與更新通知機制。

---

## Skill 來源分類

Skill 只有兩種來源，無例外：

| 來源 | 說明 |
|------|------|
| **對話延伸** | 使用者透過對話完成任務後，由 agent 協助生成 skill。包含「使用系統/Library skill + 個人特定流程」的情境。 |
| **從頭建立** | 使用者手動撰寫 `.md` 檔案建立 skill。 |

---

## Skill 區域

### 個人區（Personal Zone）
- 儲存使用者自己的 skill，無論來源為何
- 實驗性、尚未標準化，只有自己使用
- 不對外共享
- **可停用、可刪除**（使用者完全掌控）

### Library（企業 / 團隊 / 系統層）
- 審核通過的穩定 skill
- 可跨使用者共享
- 修改需走版控與審核流程
- **不可停用、不可刪除** — Library skill 一旦收錄即為永久有效，確保依賴方不受影響

---

## 來源關聯追蹤

### 自動偵測
當對話過程中使用了某個 Library / 系統 skill，agent 在生成個人 skill 時，系統自動打上來源標記：

```
derived_from: <library_skill_id>
```

### 無標記情況
- 手寫建立的 skill 預設無 `derived_from`
- 使用者可手動聲明來源（選填）
- 純粹從對話生成、未使用任何既有 Library skill 者，無標記

### 關聯不可解除
個人 skill 與其他 skill 之間的關聯（`derived_from` 等標記）一旦建立，**不可由使用者手動斷聯**。即使個人 skill 被停用或刪除，關聯記錄仍保留於系統歷史中。這確保來源追蹤的完整性，防止關聯被人為遮蔽。

## 送審流程（個人區 → Library）

### 流程總覽

```
[使用者] 發起送審
     ↓
個人 skill 狀態變為「審核中」（仍可使用，不鎖定）
     ↓
[系統] 通知團隊主管有新送審項目
     ↓
[團隊主管] 進行審核
     ↓
    通過                        未通過
     ↓                            ↓
[系統] 在 Library 建立           [系統] 通知使用者審核結果
對應標準版本                      附上主管填寫的退回原因
     ↓                            ↓
個人版狀態更新為                  個人 skill 狀態恢復「草稿」
「已有 Library 對應版」           使用者可修改後重新送審
     ↓
[系統] 通知使用者審核通過
```

### 各階段說明

**① 使用者發起送審**
- 在個人 skill 頁面點擊「送審至 Library」
- 可填寫說明（選填）：描述 skill 的適用情境、與現有 Library skill 的差異
- 送出後個人 skill 狀態標記為「審核中」，仍可正常使用，不可再編輯

**② 團隊主管審核**
- 主管收到通知，進入審核介面
- 可查看 skill 完整內容、來源標記（`derived_from`）、使用者說明
- 審核結果：
  - **通過** — 可調整 skill 名稱、描述後收錄至 Library
  - **退回** — 需填寫退回原因（必填），說明需補充或修改的方向

**③ 通過後**
- Library 新增該 skill 的標準版本（獨立版本線）
- 個人版繼續存在，標記「已有 Library 對應版」
- 個人版狀態恢復可編輯

**④ 退回後**
- 使用者收到通知與退回原因
- 個人 skill 狀態恢復「草稿」，可修改內容後重新送審
- 退回次數不限，無懲罰機制

### 審核者
團隊主管負責審核，判斷是否符合 Library 收錄標準。

## 版本更新提醒

### 觸發條件
當個人 skill 帶有 `derived_from` 標記，且對應的 Library skill 發生任何版本更新時，個人區顯示更新提醒。

- **每次更新都通知**，不過濾大小改動（使用者自行判斷是否跟進）

### 使用者選擇更新的行為
```
Library skill 更新
     ↓
個人區顯示更新提醒
     ↓
使用者點擊「更新」
     ↓
直接以 Library 最新版本建立新版個人 skill
（不論原先個人 skill 基於哪個版本，一律跳至最新）
     ↓
舊版個人 skill 保留（不覆蓋，版本號遞增）
```

**注意：** 更新操作不合併個人原有的修改，直接以 Library 最新版覆蓋生成。如需保留個人調整，使用者須在更新後手動重新加入。

### 不更新
使用者可忽略提醒，繼續使用舊版個人 skill，無強制升級。

---

## 版本規則摘要

| 操作 | 行為 |
|------|------|
| 送審 | 個人區原版保留，Library 若通過則新增標準版 |
| Library 更新 | 有 `derived_from` 的個人 skill 收到通知 |
| 使用者更新 | 生成新版個人 skill，舊版保留 |
| 手動建立的 skill | 無 `derived_from`，不受 Library 更新影響 |
| 個人 skill 停用/刪除 | 允許；關聯記錄不隨之消除 |
| Library skill 停用/刪除 | **不允許** |
| 手動斷聯 `derived_from` | **不允許**；關聯永久保留 |
